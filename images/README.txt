# 타로의 시간 — 자체 분석 웹사이트

## 파일
- index.html : 화면 구조
- style.css : 디자인
- script.js : 78장 카드 데이터, 3장 무작위 추첨, 정/역방향, 해석, localStorage 기록
- images/wizard_draw.jpg : 입력 화면 마법사
- images/wizard_advice.jpg : 출력 화면 마법사

## 실행
index.html을 브라우저에서 열면 바로 실행됩니다.

## GitHub Pages
저장소에 위 파일과 images 폴더를 그대로 올린 뒤 Settings → Pages에서 배포합니다.

## 주의
타로 결과는 오락 및 자기성찰을 위한 참고용입니다. 중요한 의사결정을 타로 결과만으로 판단하지 않도록 안내합니다.


[수정 사항]
- 역방향 카드 해석 생성 오류를 수정했습니다. 역방향 카드가 나올 때 결과 화면이 표시되지 않던 문제를 방지합니다.
- script.js 캐시 버전을 v5로 변경했습니다.
- 이미지 파일은 images 폴더에 포함했습니다.

[실행 방법]
index.html을 브라우저에서 열어 실행합니다. 수정 후에도 이전 화면이 보이면 Ctrl+F5로 새로고침하세요.
